# Security reporting

Report security-sensitive findings through
[GitHub private vulnerability reporting](https://github.com/NRux/Goliath-CNC/security/advisories/new).
Include the affected commit, impact, and a minimal reproduction using synthetic
or redacted data. Do not put credentials, raw captures or exploit details in a
public issue. If the private form is unavailable, open an issue requesting a
private reporting channel without disclosing the sensitive details.

This project is in development, with no production-supported releases or
guaranteed response time. Reports about current `main` are most useful; include
the revision for older behavior so it can be checked. The maintainer will assess
the finding and coordinate any fix and disclosure through the private report.

For ordinary bugs, installation questions and feature proposals, use the
[issue templates](https://github.com/NRux/Goliath-CNC/issues/new/choose).
For hardware concerns, report what has already happened without repeating a
test that could cause movement. Passing software checks does not clear the
[current hardware hold](README.md#hardware-status).
